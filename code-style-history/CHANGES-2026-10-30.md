## principles.md

- Rule 2 renamed; new subsection "Define errors out of existence" (Ousterhout, chapter title confirmed through Cheney §7.6). It is reconciled with rule 2 by one test: could any caller receive a plausible but wrong value without knowing? It also says to redefine only the case you mean, which is what separates `missing_ok` from `ignore_errors`. Its last bullet carries Pike's all-or-nothing idea across languages.
- Rule 4: one term per concept (Hilton slide 53; Cheney §2.4), a list of vague words (Hilton slides 51, 52, 70), name the contents rather than the type (Cheney §2.3), and the one-sentence test (Cheney §3.2 tip; Hilton slides 85, 88).
- Rule 5: "test through the public interface; a private function only when..." moved here from python.md, since go.md now depends on it. Added: never widen visibility only for a test.
- Sources: Pike, Cheney, Hilton.

## go.md

- Functions: narrowest interface plus "whoever opened it closes it" (replaces a restatement of principle 1); no `nil` standing for a default; adjacent same-type parameters (all Cheney §6).
- Errors: keep-the-first-error pattern, `bufio.Writer` first, and the `io.Writer` contract as a MUST. Departs from Cheney's `errWriter`, which returns `n, nil`; `pipeline_test.go` demonstrates the violation.
- New section, Sequences: slice by default; `iter.Seq`/`Seq2` with the `iter` package's naming, `yield`, single-use, and `Pull` rules; no channel-returned sequences (CRC "Synchronous Functions", Cheney §9.4); `iter.Seq2[T, error]` for sequences that can fail, as a house rule.
  - Evidence for the house rule: there is no official guidance. The 1.26.2 standard library has no `Seq2[..., error]`, and the Go 1.27 release notes add none; its fallible streams keep the `Scan`/`Err` shape. Chosen because an unused `err` range variable fails to compile (verified), while a forgotten `Err()` compiles silently.
- Time: the clock-injection line was deleted as a duplicate of principle 1.
- Tests: `package foo_test` by default, with `foo_internal_test.go` for the principle 5 exception and `Example` functions in `foo_test` (house rule; `testing` allows both). The fakes line was trimmed to the part principle 5 does not already say.

## python.md

- Exceptions: use the library flag for the case defined away (`missing_ok`, `exist_ok`, `not_found_ok`); `suppress(OneError)` when there is no flag; never `rmtree(ignore_errors=True)`. `create_dataset(exists_ok=True)` returns the existing dataset without comparing settings, verified in `client.py`.
- Tests: removed two lines that now live in principle 5.
